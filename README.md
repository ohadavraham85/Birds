# יומן צפרות 🦉 — מערכת לניהול ותיעוד תצפיות (POC)

אפליקציית **PWA** (Progressive Web App) לתיעוד תצפיות צפרות בשטח.

**גרסת POC — הכול בקליינט בלבד:** אין צד שרת, אין חשבונות ואין הגדרות —
פותחים ומתחילים לעבוד. כל הנתונים (כולל תמונות באיכות מקור) נשמרים מקומית
במכשיר (IndexedDB) והאפליקציה עובדת באופן מלא גם ללא רשת. גיבוי ושחזור
מתבצעים בקובץ JSON יחיד ממסך ההגדרות.

## פלטפורמה אחת — שלוש תצורות

בזכות פורמט ה-PWA אותה מערכת מותקנת בכל המכשירים:

| תצורה | איך מתקינים |
|---|---|
| 📱 **מובייל / טאבלט (Android)** | פותחים את הכתובת ב-Chrome → תפריט ⋮ → "הוספה למסך הבית" / "התקנת אפליקציה" |
| 📱 **iPhone / iPad** | פותחים ב-Safari → כפתור שיתוף → "הוסף למסך הבית" |
| 💻 **דסקטופ (Windows / Mac)** | פותחים ב-Chrome / Edge → סמל ההתקנה ⊕ בשורת הכתובת → "התקנה" (נפתחת כתוכנה בחלון עצמאי) |
| 🌐 **דפדפן** | גלישה רגילה לכתובת האתר |

## תכונות עיקריות

- **טופס דיווח אחוד** — מסך אחד רציף: תאריך ושעה (ברירת מחדל: עכשיו), מיקום,
  קואורדינטות GPS אוטומטיות, פרויקט, מין הציפור, כמות, תמונות והערות. שמירה בלחיצה אחת.
- **בחירת מין מרשימת מאסטר** — תיבה נפתחת עם חיפוש והשלמה אוטומטית; אין הזנה חופשית ואין שגיאות כתיב.
  הרשימה מגיעה עם ~100 מינים נפוצים בישראל וניתנת לעריכה מלאה במסך ההגדרות.
- **תמונות באיכות מקור** — העלאה מהגלריה (כולל קבצים ממצלמות מקצועיות/רחפן) או צילום ישיר;
  הקבצים נשמרים ללא שום כיווץ.
- **4 תצוגות** — טופס, מפת שטח עם סיכות (Leaflet/OpenStreetMap), רשימה טבלאית (חדש למעלה), ויומן כרטיסים.
- **ייבוא CSV מרוכז** — קובץ אחד ⟵ כל השורות נטענות בבת אחת.
- **סימון מרובה וייצוא PDF** — בחירת תצפיות ברשימה והפקת דו"ח RTL מעוצב אחד שמורד למכשיר.
- **טקסט עשיר בהערות** — פסקאות וירידות שורה נשמרות כפי שהוקלדו; תמיכה ב-Markdown (הדגשות, כותרות, רשימות) בתצוגה.
- **גיבוי ושחזור** — קובץ JSON יחיד עם כל התצפיות, המינים והתמונות; ניתן לשחזור בכל מכשיר.

## הפעלה מקומית / פריסה

זהו אתר סטטי — אין build ואין שרת:

```bash
npx http-server -p 8080
# או
python3 -m http.server 8080
```

לפריסה קבועה: כל אחסון סטטי (GitHub Pages / Netlify / Cloudflare Pages).
נדרש **HTTPS** (דרישה של PWA, מצלמה ו-GPS); `localhost` פטור.

## פורמט CSV לייבוא

שורת כותרות + שורה לכל תצפית. שמות עמודות נתמכים בעברית או באנגלית:

```csv
תאריך ושעה,מיקום,קואורדינטות,פרויקט,מין הציפור,מספר פרטים,הערות
2026-06-15 06:30,נחל שחל,"32.606, 35.472",קינון חיוויאים,חיוויאי הנחשים,2,"קן על שיזף.
בקיעת גוזל!"
15/05/2026 05:45,מחצבת שדה אליהו,"32.441, 35.510",אוחים,אוח מצוי,5,זוג + 3 פרחונים
```

(אפשר גם עמודות `lat` / `lng` נפרדות במקום "קואורדינטות".)
מינים שלא קיימים ברשימת המאסטר מתווספים אליה אוטומטית בזמן הייבוא.

## מבנה הקוד

```
index.html            שלד האפליקציה (RTL)
manifest.webmanifest  הגדרות PWA והתקנה
sw.js                 Service Worker — עבודה ללא רשת
css/app.css           עיצוב
js/
  app.js              אתחול וניווט
  db.js               שכבת IndexedDB (כל האחסון)
  media.js            שליפת תמונות מהאחסון המקומי
  csv.js              ייבוא/ייצוא CSV
  pdf.js              הפקת דו"ח PDF
  markdown.js         רינדור טקסט עשיר בהערות
  species-seed.js     רשימת מינים התחלתית
  views/              חמשת המסכים (טופס, מפה, רשימה, יומן, הגדרות)
vendor/               Leaflet + html2pdf (מקומיים — עובדים גם offline)
```

ללא framework וללא תהליך build — JavaScript מודולרי טהור.

## בנייה וגרסאות (CI)

כל push מפעיל GitHub Action שבודק את הקוד, מטביע מספר גרסה
(`version.json` + עדכון מטמון ה-Service Worker), יוצר טאג `vX.Y.Z`
ומפרסם Release עם ZIP להורדה.

## המשך פיתוח (מעבר ל-POC)

הארכיטקטורה מוכנה להוספת סנכרון ענן (למשל Google Drive/Sheets) בשכבה
נפרדת מעל `db.js`, ללא שינוי במסכים — גרסה מוקדמת של שכבה כזו קיימת
בהיסטוריית ה-git (`js/drive.js`).
