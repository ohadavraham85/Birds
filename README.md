# יומן צפרות 🦉 — מערכת לניהול ותיעוד תצפיות

אפליקציית **PWA** (Progressive Web App) חוצת-פלטפורמות לתיעוד תצפיות צפרות בשטח.
פועלת באופן מלא **ללא רשת** (offline-first) וכל הנתונים מאוחסנים **בלעדית בחשבון
ה-Google Drive הפרטי שלך** — גיליון Google Sheets עם שני גיליונות ("תצפיות"
ו"רשימת מינים") ותיקיות לתמונות באיכות מקור ולדוחות PDF.

## פלטפורמה אחת — שלוש תצורות

בזכות פורמט ה-PWA אותה מערכת מותקנת ומסונכרנת בכל המכשירים:

| תצורה | איך מתקינים |
|---|---|
| 📱 **מובייל / טאבלט (Android)** | פותחים את הכתובת ב-Chrome → תפריט ⋮ → "הוספה למסך הבית" / "התקנת אפליקציה" |
| 📱 **iPhone / iPad** | פותחים ב-Safari → כפתור שיתוף → "הוסף למסך הבית" |
| 💻 **דסקטופ (Windows / Mac)** | פותחים ב-Chrome / Edge → סמל ההתקנה ⊕ בשורת הכתובת → "התקנה" (נפתחת כתוכנה בחלון עצמאי) |
| 🌐 **דפדפן** | גלישה רגילה לכתובת האתר |

## תכונות עיקריות

- **טופס דיווח אחוד** — מסך אחד רציף: תאריך ושעה (ברירת מחדל: עכשיו), מיקום,
  קואורדינטות GPS אוטומטיות, פרויקט, מין הציפור, כמות, תמונות והערות. שמירה בלחיצה אחת.
- **בחירת מין מרשימת מאסטר** — תיבה נפתחת עם חיפוש והשלמה אוטומטית; אין הזנה חופשית ואין שגיאות כתיב.
- **תמונות באיכות מקור** — העלאה מהגלריה (כולל קבצים ממצלמות מקצועיות/רחפן) או צילום ישיר;
  הקבצים נשמרים ל-Drive ללא כיווץ, בשם המקושר למזהה התצפית.
- **4 תצוגות** — טופס, מפת שטח עם סיכות (Leaflet/OpenStreetMap), רשימה טבלאית (חדש למעלה), ויומן כרטיסים.
- **ייבוא CSV מרוכז** — קובץ אחד ⟵ כל השורות נשפכות לגיליון התצפיות בבת אחת.
- **סימון מרובה וייצוא PDF** — בחירת תצפיות ברשימה והפקת דו"ח מעוצב אחד, שמורד למכשיר ונשמר ב-Drive.
- **טקסט עשיר בהערות** — פסקאות וירידות שורה נשמרות כפי שהוקלדו; תמיכה ב-Markdown (הדגשות, כותרות, רשימות) בתצוגה.
- **עבודה בשטח ללא קליטה** — הכול נשמר מקומית (IndexedDB) ומסתנכרן לענן בלחיצת "סנכרון".

## הפעלה מקומית / פריסה

זהו אתר סטטי — אין צורך בשרת צד-שרת:

```bash
# הרצה מקומית
npx http-server -p 8080
# או
python3 -m http.server 8080
```

לפריסה קבועה אפשר להשתמש בכל אחסון סטטי: **GitHub Pages**, Netlify, Vercel,
Cloudflare Pages וכו'. חובה **HTTPS** (דרישה של PWA, מצלמה ו-GPS).

## חיבור ל-Google Drive (חד-פעמי, ~5 דקות)

האפליקציה ניגשת ל-Drive ישירות מהדפדפן בהרשאת `drive.file` — כלומר היא רואה
**רק** קבצים שהיא עצמה יצרה. כדי לחבר:

1. נכנסים אל [Google Cloud Console](https://console.cloud.google.com/) ויוצרים פרויקט חדש.
2. **APIs & Services → Library** — מפעילים את **Google Drive API** ואת **Google Sheets API**.
3. **APIs & Services → OAuth consent screen** — בוחרים External, ממלאים שם אפליקציה ואימייל,
   ומוסיפים את עצמכם כ-Test user (או מפרסמים את האפליקציה).
4. **APIs & Services → Credentials → Create Credentials → OAuth client ID**:
   - Application type: **Web application**
   - **Authorized JavaScript origins**: הכתובת שבה האפליקציה מתארחת
     (למשל `https://username.github.io`, וגם `http://localhost:8080` לפיתוח).
5. מעתיקים את ה-**Client ID** (מסתיים ב-`.apps.googleusercontent.com`) ומדביקים אותו
   במסך **הגדרות ← חיבור ל-Google Drive** באפליקציה, ולוחצים "התחברות וסנכרון".

בסנכרון הראשון נוצרים אוטומטית בחשבונכם:

- 📄 גיליון **"תצפיות צפרות - בסיס נתונים"** ובו שני גיליונות: **תצפיות** ו-**רשימת מינים**
- 📁 תיקייה **"תצפיות צפרות - תמונות"** (קבצי מקור מלאים)
- 📁 תיקייה **"תצפיות צפרות - דוחות"** (קובצי ה-PDF המיוצאים)

אותו Client ID משמש את כל המכשירים שלכם — וכולם מסתנכרנים לאותו גיליון.

## פורמט CSV לייבוא

שורת כותרות + שורה לכל תצפית. שמות עמודות נתמכים בעברית או באנגלית:

```csv
תאריך ושעה,מיקום,קואורדינטות,פרויקט,מין הציפור,מספר פרטים,הערות
2026-06-15 06:30,נחל שחל,"32.606, 35.472",קינון חיוויאים,חיוויאי הנחשים,2,"בקיעת גוזל בקן על השיזף"
15/05/2026 05:45,מחצבת שדה אליהו,"32.441, 35.510",אוחים,אוח מצוי,5,זוג + 3 פרחונים
```

(אפשר גם עמודות `lat` / `lng` נפרדות במקום "קואורדינטות".)

## מבנה הקוד

```
index.html            שלד האפליקציה (RTL)
manifest.webmanifest  הגדרות PWA והתקנה
sw.js                 Service Worker — עבודה ללא רשת
css/app.css           עיצוב
js/
  app.js              אתחול, ניווט, כפתור סנכרון
  db.js               שכבת IndexedDB (אחסון מקומי)
  drive.js            OAuth + סנכרון דו-כיווני ל-Google Drive/Sheets
  csv.js              ייבוא/ייצוא CSV
  pdf.js              הפקת דו"ח PDF
  markdown.js         רינדור טקסט עשיר בהערות
  species-seed.js     רשימת מינים התחלתית
  views/              חמשת המסכים (טופס, מפה, רשימה, יומן, הגדרות)
vendor/               Leaflet + html2pdf (מקומיים — עובדים גם offline)
```

ללא framework וללא תהליך build — JavaScript מודולרי טהור.
